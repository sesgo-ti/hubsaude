# Portal Tests

Run from `website/` after dependencies, Chromium and the production build are available:

```sh
node --test tests/build.test.mjs
npm run test:browser
# Both suites, in order:
npm test
```

The suites do not install dependencies, rebuild the portal, run CLI examples or contact production services. Playwright starts `node tests/serve.mjs` on port 4173. The server exposes only `build/` at `/hubsaude/`, returns real 404 responses, rejects traversal and checks symlink containment. Port 4173 must be free.

## Frozen Fixtures

`legacy-routes.json` is the migration's original inventory of 14 pages and every legacy ID. It is not regenerated by tests.

`legacy-code.json` was captured from the original HTML before removal. It stores the exact HTML of all 12 language templates and 27 preformatted examples, their original order and source-page SHA-256 hashes. No test reads `site/`. Keeping HTML preserves the original entity decoding and template-document-fragment behavior. Cheerio extracts expected text, removing only the single opening/closing newline that the original template renderer removed. Generated Prism lines are joined with newlines, including blank lines; indentation and code content are not trimmed or normalized. CLI illustration and OS installers are new blocks, so its original example is checked as an ordered exact match rather than requiring identical block counts.

## Coverage

- Canonical pages, canonical metadata, legacy URLs and all frozen IDs.
- Generated HTML/SVG links, image/source sets, scripts, CSS imports/URLs, assets and target fragments, including fragments carried through legacy redirects. External URLs are ignored without fetching them. Only canonical/hreflang metadata on the generated `404.html` is excluded because Docusaurus gives it a synthetic SEO URL; its navigation and assets are still validated. Relative canonical URLs in official plugin redirects are resolved against the legacy URL.
- Chromium desktop 1440x1000 and mobile 390x844: page errors, failed local resources, outbound requests, horizontal body/document overflow and the state crest's URL, accessible name and natural width.
- All three language groups: four languages, exact displayed examples, real clipboard contents, reload persistence, independent preferences, left/right wraparound and Enter activation.
- Native Home/End support is probed and reported as test annotations and a JSON attachment, not presumed. Current Docusaurus does not implement those keys.
- Mobile navigation to managers/developers and all four SDKs; OS installer switching, persistence and exact prompt-free clipboard text.
- Initial home/auth/manager/CLI content without JavaScript; tabs with localStorage access denied.
- Strict server 404s, methods, SVG MIME/HEAD responses and raw/encoded traversal rejection.

Full-page home/auth/manager/CLI screenshots are attached using `testInfo.outputPath()` under ignored `test-results/`, separately for each viewport. They are review artifacts, not visual golden assertions. Browser workers are serial because the real OS clipboard can be shared across Chromium contexts.
