# Portal Tests

Run from `website/` after dependencies, Chromium and the production build are available:

```sh
node --test tests/*.test.mjs
npm run test:browser
# Both suites, in order:
npm test
```

The suites do not install dependencies, rebuild the portal, run CLI examples or contact production services. Playwright starts `node tests/serve.mjs` on port 4173. The server exposes only `build/` at `/hubsaude/`, returns real 404 responses, rejects traversal and checks symlink containment. Port 4173 must be free.

## Frozen Fixtures

`legacy-routes.json` is the migration's original inventory of 14 pages and every legacy ID. It is not regenerated by tests.

`legacy-code.json` was captured from the original HTML before removal. It stores the exact HTML of all 12 language templates and 27 preformatted examples, their original order and source-page SHA-256 hashes. No test reads `site/`. Keeping HTML preserves the original entity decoding and template-document-fragment behavior. Cheerio extracts expected text, removing only the single opening/closing newline that the original template renderer removed. Generated Prism lines are joined with newlines, including blank lines; indentation and code content are not trimmed or normalized. CLI illustration and OS installers are new blocks, so its original example is checked as an ordered exact match rather than requiring identical block counts.

`gestor-upstream.json` freezes the upstream manager page's provenance, prose, headings, eyebrows, ordered application/approval steps, levels, table, contact, legacy IDs and nine screenshots. Static tests compare all of those against the generated page, collapsing only whitespace in prose and excluding Docusaurus's added heading permalink glyph. The sole approved navigation-label exception is `Enviar e-mail para solicitar credenciamento`, asserted separately in `navigation.mjs` and the suites; the fixture retains its original arrow label and the contact destination remains unchanged. Each screenshot's summary, description and alt text must match exactly; both the source image and the image actually referenced by the build must retain the frozen SHA-256. Tests never regenerate or modify fixtures.

## Coverage

- All 14 frozen canonical pages, canonical metadata, legacy URLs and original IDs, plus `/sobre/`, `/fluxos/preparar/` and `/fluxos/visao-geral/` with their canonical IDs. The sitemap must contain exactly those 17 content routes (search is excluded).
- `navigation.mjs` reads the application's `src/data/home-sections.json`, not a second fragment fixture. Every moved legacy ID must have a real static aside link to an existing destination fragment. Each mapping is tested in the browser on both `/hubsaude/` and `/hubsaude/index.html`, preserving an encoded, repeated-parameter query and replacing browser history. The original `index.html#rtitle` now resolves to `/fluxos/visao-geral/#jornada`.
- Without JavaScript, both home URL forms show only the targeted fallback aside; its actionable link is keyboard-activated and must reach the destination document and ID. Untargeted fallback asides remain hidden, not empty anchor placeholders.
- Browser-visible home content has exactly two body links (manager and developer), no home search form, exactly one navbar search, only brand/audience navbar links and one `Suporte` footer link.
- Generated HTML/SVG links, image/source sets, scripts, CSS imports/URLs, assets and target fragments, including fragments carried through legacy redirects. External URLs are ignored without fetching them. Only canonical/hreflang metadata on the generated `404.html` is excluded because Docusaurus gives it a synthetic SEO URL; its navigation and assets are still validated. Relative canonical URLs in official plugin redirects are resolved against the legacy URL.
- Chromium desktop 1440x1000 and mobile 390x844: page errors, failed local resources, outbound requests, horizontal body/document overflow and the state crest's URL, accessible name and natural width. Additional mobile home cases at 360 and 390 pixels assert no overflow or brand/search overlap.
- All three language groups: four languages, exact displayed examples, real clipboard contents, reload persistence, independent preferences, left/right wraparound and Enter activation.
- Native Home/End support is probed and reported as test annotations and a JSON attachment, not presumed. Current Docusaurus does not implement those keys.
- Both audience paths and mobile navbar links reach their documentation. Native next/previous pagination follows `/fluxos/` -> `preparar` -> `autenticacao` -> `envio-recurso`, then stops. The initially collapsed reference sidebar category opens with the keyboard on desktop/mobile and reaches the SDK catalog and all four SDKs, without a navbar SDK shortcut.
- OS installer switching, persistence and exact prompt-free clipboard text. Initial home/flow/prepare/reference/auth/manager/CLI content without JavaScript; tabs with localStorage access denied.
- Strict server 404s, methods, SVG MIME/HEAD responses and raw/encoded traversal rejection.
- Home navbar search fills `certificado` and follows `Ver todos os resultados`, finding managers/authentication and navigating to the exact certificate heading. Document-navbar search finds the Python SDK. Accented/unaccented Portuguese queries, empty/zero-result Portuguese guidance and accessible search names/landmark remain covered, as do all nine manager Details with keyboard interaction and all nine screenshots without JavaScript.
- Search uses the actual generated index and dedicated web worker, without mocked results. The existing context-level request guard covers worker fetches as well as page assets; worker origins, browser/console errors and failed responses are checked too. Service workers remain blocked. The home search explicitly waits for a local worker and a successful `/hubsaude/search-index*.json` response.
- `search-index.test.mjs` verifies cache invalidation when docs, filenames, indexing options, site configuration, sidebar or indexing code change. Temporary fixtures are removed automatically.
- `search-resilience.spec.mjs` deliberately fails index and worker requests, delays worker replies and exercises constructor/startup failures. The UI must recover through retry without a reload, reject stale results and synchronize browser history. Only deliberately injected HTTP errors are excluded from console assertions.
- Unknown home fragments, including inherited object-property names, must leave the two-entry page usable without exceptions or redirects.

Full-page home/flow/prepare/reference/auth/manager/CLI screenshots are attached using `testInfo.outputPath()` under ignored `test-results/`, separately for each viewport. Additional captures are `search-page.png`, `search-menu.png` (viewport), `gestor-expanded.png` and `gestor-no-js-expanded.png`. Each lives in its test's desktop/mobile output directory and is also attached to the test result. They are review artifacts, not visual golden assertions. Browser workers are serial because the real OS clipboard can be shared across Chromium contexts.

The search regression tests cover the plugin defects corrected by the versioned patch: accentless queries, a main landmark and Portuguese accessible names. They are not skipped or marked as expected failures. These tests use only port 4173 and do not touch a preview on port 3000 or rebuild application files.
