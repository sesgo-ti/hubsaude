# Ferramentas para integradores

Estas ferramentas rodam na sua própria máquina e permitem conferir se os dados estão no formato certo e se a autenticação funciona, antes de apontar o sistema para produção.

## HubSaúde CLI

O programa de linha de comando que instala e comanda as ferramentas locais. É por ele que você valida arquivos e sobe os ambientes de teste na sua máquina.

- [Ver CLI](cli.mdx)

## Validador

Confere se um registro de saúde está de acordo com as regras dos Guias de Implementação e aponta o que precisa ser corrigido.

- [Ver Validador](validador.mdx)

## Simulador

Uma cópia local do HubSaúde para testar seu cliente de ponta a ponta, com as mesmas exigências de segurança da produção.

- [Ver Simulador](simulador.mdx)

## Safira

Assina e valida documentos FHIR conforme a política de assinatura

- [Repositório](https://github.com/sesgo-ti/safira)
- [Política](https://fhir.saude.go.gov.br/r4/seguranca/assinatura.html)

## Contrato FHIR

Descreve o que o servidor aceita, em CapabilityStatement e OpenAPI

- [FHIR NPM (.tgz)](https://hub.saude.go.gov.br/downloads/hubsaude-capabilities)
- [OpenAPI (.json)](https://hub.saude.go.gov.br/downloads/openapi-hubsaude-fhir)

## Coleção do produtor

Requisições prontas para executar o fluxo de escrita (Bruno e .http)

- [Bruno + .http (.zip)](https://hub.saude.go.gov.br/downloads/hubsaude-colecao-produtor)
