Validador

O Validador confere se um registro de saúde está de acordo com as regras dos Guias de Implementação e aponta o que precisa ser corrigido. Ele roda na sua máquina: o HubSaúde CLI baixa e inicia a ferramenta quando você precisa dela, e não existe versão hospedada.

Use apenas dados sintéticos. Nunca envie informação real de pacientes ao Validador. Trabalhe sempre com instâncias de teste inventadas. A própria interface da ferramenta mantém esse aviso visível o tempo todo.

1. Uso

Validando recursos

O caso mais simples é validar um arquivo. O mesmo comando também aceita uma pasta inteira, texto vindo da entrada padrão e diferentes formatos de saída.

# um arquivo
hubsaude validate paciente.json

# todos os recursos de um diretório
hubsaude validate --dir ./recursos/

# lendo da entrada padrão
cat paciente.json | hubsaude validate -

Inspeção no navegador

hubsaude validate --output web abre uma tela onde você percorre os problemas encontrados, recurso a recurso.

Uso em automação

hubsaude validate --output json devolve o resultado em formato legível por máquina, adequado a pipelines de CI. Para checar contra um perfil específico, acrescente --profile <url>.

2. Serviço local

Ciclo de vida do serviço

Por trás do comando, o Validador fica rodando como um serviço na sua máquina, iniciado automaticamente no primeiro uso. Para consultar o estado ou encerrá-lo, use os comandos abaixo.

hubsaude validate server status
hubsaude validate server stop

A porta usada pode ser alterada com a variável HUBSAUDE_VALIDADOR_PORT. Veja as variáveis de ambiente.
