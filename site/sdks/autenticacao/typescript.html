SDK TypeScript

Biblioteca cliente TypeScript/Node.js (hubsaude-cliente-js, consumível também por JavaScript puro). O uso é exclusivamente em servidor, nunca em navegador ou app móvel.

Ver o fluxo de Autenticação →
1. Instalação

Instalação

Ainda não publicado no registro npm público. Até a primeira publicação, instale a partir de um tarball gerado por npm pack no repositório, ou aponte para o Git diretamente.

npm install hubsaude-cliente-js
2. Uso básico

Uso básico

createSmartTokenClient é a única forma de construção (a classe não tem construtor público). Chame close() uma vez no encerramento, ou use await using client = await createSmartTokenClient(...).

import { createSmartTokenClient } from "hubsaude-cliente-js";

const client = await createSmartTokenClient({
  tokenEndpoint: "https://hub.saude.go.gov.br/auth/token",
  clientId: "meu-sistema",
  privateKeyPem: "chave-privada.pem",
  certificatePem: "certificado.pem",
});

const token = await client.obtainToken("system/Patient.rs");
3. Fontes de chave

Fontes de chave suportadas

Sua chave privada pode estar em diferentes lugares: um arquivo, um cofre de segredos ou um dispositivo de hardware. O SDK abstrai isso com o tipo SigningStrategy, uma função que recebe os bytes a assinar e devolve a assinatura, e já traz pronta a construção para as fontes mais comuns.

PEM com senha

const client = await createSmartTokenClient({
  tokenEndpoint: "https://hub.saude.go.gov.br/auth/token",
  clientId: "meu-sistema",
  privateKeyPem: "chave-encrypted.pem",
  privateKeyPassword: Buffer.from("minha-senha"),
});

PKCS#12 direto (recomendado para produção)

Um único arquivo (.pfx/.p12) já reúne a chave e o certificado, protegido por senha.

import { readFile } from "node:fs/promises";
import { createSmartTokenClient, fromPkcs12 } from "hubsaude-cliente-js";

const pfx = await readFile("certificado.pfx");

const client = await createSmartTokenClient({
  tokenEndpoint: "https://hub.saude.go.gov.br/auth/token",
  clientId: "meu-sistema",
  signingStrategy: fromPkcs12(pfx, "senha-pfx"),
  clientPfx: pfx,
  clientPfxPassphrase: "senha-pfx",
});

HSM via PKCS#11

Um HSM (Hardware Security Module) é um dispositivo dedicado que guarda a chave e nunca a expõe: toda assinatura acontece dentro dele. Node não tem suporte nativo a PKCS#11 (o padrão usado para acessar o HSM), então pkcs11js entra como peer dependency opcional (npm install hubsaude-cliente-js pkcs11js).

import { createSmartTokenClient, fromPkcs11 } from "hubsaude-cliente-js";

const signingStrategy = await fromPkcs11({
  library: "/usr/lib/softhsm/libsofthsm2.so",
  tokenLabel: "meu-token",
  keyLabel: "minha-chave-hsm",
  pin: "123456",
  jwtAlgorithm: "ES384",
});

const client = await createSmartTokenClient({
  tokenEndpoint: "https://hub.saude.go.gov.br/auth/token",
  clientId: "meu-sistema",
  signingStrategy,
});
