SDK Python

Biblioteca cliente Python (hubsaude-client) para obtenção de access tokens via SMART Backend Services.

Ver o fluxo de Autenticação →
1. Instalação

Instalação

Ainda não publicado no PyPI. Instale a partir do código-fonte (branch develop):

git clone https://github.com/sesgo-ti/hubsaude-cliente-python.git
cd hubsaude-cliente-python
pip install -e .

O extra opcional hsm (pip install "hubsaude-client[hsm]") traz a dependência python-pkcs11, necessária apenas para assinatura via HSM/smart token.

2. Uso básico

Uso básico

SmartTokenClientBuilder monta o cliente passo a passo e valida a configuração antes de criar a instância. Reutilize o mesmo cliente durante todo o ciclo de vida da aplicação e chame close() uma única vez ao encerrar, ou use o gerenciador de contexto with.

from hubsaude_client.builder import SmartTokenClientBuilder

client = (
    SmartTokenClientBuilder()
    .client_id("meu-client-id")
    .token_endpoint("https://auth.hubsaude.exemplo/token")
    .private_key_pem("/caminho/para/chave-privada.pem")
    .build()
)

resultado = client.obtain_token(scope="system/Patient.rs")
print(resultado)

client.close()
3. Fontes de chave

Fontes de chave suportadas

Sua chave privada pode estar em diferentes lugares: um arquivo, um cofre de segredos ou um dispositivo de hardware. O SDK abstrai isso com um contrato simples, hubsaude_client.SigningStrategy (um Protocol com um único método, sign(bytes) -> bytes), e já traz pronta uma factory para as quatro fontes mais comuns em hubsaude_client.strategy_factory.

PEM com senha

client = (
    SmartTokenClientBuilder()
    .client_id("meu-client-id")
    .token_endpoint("https://auth.hubsaude.exemplo/token")
    .private_key_pem("/caminho/chave-encrypted.pem", password=bytearray(b"minha-senha"))
    .build()
)

PKCS#12 direto

Um único arquivo (.pfx/.p12) já reúne a chave e o certificado, protegido por senha. .client_key_store(path, password) resolve os dois de uma vez: a assinatura e o certificado de cliente para mTLS.

client = (
    SmartTokenClientBuilder()
    .client_id("meu-client-id")
    .token_endpoint("https://auth.hubsaude.exemplo/token")
    .client_key_store("certificado.pfx", "senha-pfx")
    .build()
)

HSM via PKCS#11

Um HSM (Hardware Security Module) é um dispositivo dedicado que guarda a chave e nunca a expõe: toda assinatura acontece dentro dele. Requer o extra opcional hsm; o SDK mantém apenas um handle de sessão PKCS#11.

from hubsaude_client.strategy_factory import from_pkcs11

strategy = from_pkcs11(
    pkcs11_module_path="/usr/lib/softhsm/libsofthsm2.so",
    token_label="meu-token",
    key_label="minha-chave-hsm",
    user_pin="123456",
)

client = (
    SmartTokenClientBuilder()
    .client_id("meu-client-id")
    .token_endpoint("https://auth.hubsaude.exemplo/token")
    .signing_strategy(strategy)
    .build()
)
